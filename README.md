# A structurally coherent, STAT-regulated dark proteome in Penaeus monodon hemocytes

Calibrated protein-language-model function transfer, evaluated as homologous evidence is withdrawn, and applied to the STAT-dependent uncharacterised fraction of the *Penaeus monodon* hemocyte proteome.

> **Status.** Manuscript in preparation. This repository is the code and the derived results; the archived release carries the DOI cited in the paper.

## Layout

```
scripts/     numbered pipeline, run in order
src/pmdark/  importable package: config, embedding, transfer, GO evaluation
config/      config.yaml — every path and parameter
slurm/       batch scripts for the GPU stages
envs/        conda exports, one per environment (see envs/INDEX.md)
figures/     the paper's figures, in PNG, PDF, SVG and TIFF
results/     result files; every number in the paper comes from these
docs/        design limits and assembly strategy
```

## Reproducing

The pipeline runs across more than one conda environment — `envs/INDEX.md` records which environment holds which tool, because DIAMOND, the PLM stack and the differential-expression stack are not installed together.

```bash
conda create --name busco --file envs/busco.explicit.txt
conda create --name esmprobe --file envs/esmprobe.explicit.txt
conda create --name gmx_gpu --file envs/gmx_gpu.explicit.txt
```

Then edit `config/config.yaml` to point at your own storage and run the numbered scripts in order. Scripts 31 onward reproduce every figure and table from the files already in `results/`, without re-running the GPU stages.
